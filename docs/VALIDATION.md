## Read-Only Audit of Local MIMIC Tables

`tests/audit_local_data.py` was run against the locally available source MIMIC and rule-table directories. It read full small metadata tables for aggregate cohort-stage screening, the first 200,000 rows of each event table, and the first 400,000 note rows. Event and note prefix counts are not representative population estimates. The script wrote aggregate results under the ignored target `.qa/` directory; it did not write to the source directory or retain patient-level text in the release.

The 3/20 missing-structured exclusion figures are likewise not asserted as reproduced.

Other aggregate results:

- The first 200,000 `CHARTEVENTS.csv` rows yielded 31,422 configured early-window observations; the first 200,000 `LABEVENTS.csv` rows yielded 5,602.
- The sampled event prefix covered 197 admissions with at least one mapped structured observation. A two-case random GRU smoke returned finite logits for 29 variables and 58 value/observation channels; this assessed tensor handling only.
- The first 400,000 `NOTEEVENTS.csv` rows matched 160,605 note records to the metadata cohort; 55,217 had a chart time and 26,784 passed the implemented early-window and category screening. Discharge-summary and deidentification-placeholder assertions passed for selected notes.
- `D_ITEMS.csv` and `D_LABITEMS.csv` were not available in the checked data directory. The feature count and configured ITEMID mapping were inspected, but code-to-dictionary semantics could not be independently verified. Comprehensive CareVue coverage is not established.

## Regression Coverage

The 45 tests cover patient-disjoint folds and fixed test membership; chronological first-admission CMI; 24-hour raw-time boundaries; train-only statistics; leading/internal missing-value handling and padding masks; note placeholders, paragraph deduplication, timing and category exclusions; the LG-GCMN equations and prior-adjusted training loss; raw-logit inference; fivefold mean protection; undefined-class AUC behavior; the default lambda; model padding invariance; baseline and ablation routes; severity-family handling; peak versus centroid semantics; text-span attribution; report artifact integrity; and experiment scheduling.

## Not Fully Verified

- No real-data model was trained or evaluated end to end; no full event-table or note-table extraction was run.
- CUDA was unavailable. The manuscript's 4096-token training workload was not tested on an RTX 4090 or under another GPU memory budget.
- The public repository contains no pretrained encoder weights, CAML word vectors, checkpoints, or private run outputs. Synthetic tests generate their own tiny random encoders. Historical artifacts present in local workspaces have not been linked to the latest manuscript's five folds or result tables.
- Historical patient split, exact note threshold, gradient-accumulation count, per-fold checkpoints/predictions, CMI patient subset used for reported values, and Table 4's noninteger temporal-peak calculation remain unverified.
- The all-class macro-AUC is reported undefined when any class lacks positive or negative examples; the paper does not specify this edge case. The implementation records the defined-class mean separately.

No metrics from synthetic data or sampled event/note prefixes should be interpreted as manuscript results or model performance.
